Metrolist 13.4.0 requires **Android 8.0 (API 26)** or later. Choose a download source below.

<Note>
  Metrolist ships in two build variants:

  - **FOSS** — the default variant. No Google Play Services dependency, no Google Cast support. Recommended for most users and compatible with F-Droid-based repositories.
  - **GMS** — includes Google Cast support for casting to Chromecast and other Cast-compatible devices. Requires Google Play Services.

  The IzzyOnDroid repository distributes its own FOSS variant with the built-in updater disabled (the repository handles updates instead).
</Note>

## Installation

<Steps>
  <Step title="Download the APK">
    Pick a source from the table above and download the APK file to your Android device. For GitHub Releases, tap the `.apk` link on the releases page or use the direct download link above.
  </Step>
  <Step title="Allow installation from unknown sources">
    If you are installing from a source other than the Google Play Store, Android will ask you to allow installation from that source. When prompted, tap **Settings** and enable **Allow from this source** for your browser or file manager.

    This setting is scoped to the app you install from — you do not need to enable it system-wide.
  </Step>
  <Step title="Install the APK">
    Open the downloaded APK file. Tap **Install** and wait for the installation to complete.
  </Step>
  <Step title="Open Metrolist">
    Launch Metrolist from your app drawer. You can start browsing YouTube Music immediately — no account required. To sync your library, see [account login](/setup/account-login).
  </Step>
</Steps>

## Choosing a build variant

| Variant | Google Cast | Built-in updater | Compatible with F-Droid repos |
|---------|-------------|-----------------|-------------------------------|
| FOSS (default) | No | Yes | Yes |
| GMS | Yes | Yes | No |
| IzzyOnDroid | No | No | Yes |

If you do not use Chromecast or other Cast devices, use the **FOSS** variant. If you want to cast music to a TV or speaker, use the **GMS** variant from GitHub Releases or Obtainium.

## Updating Metrolist

- **Obtainium** — updates automatically when a new release is published on GitHub.
- **IzzyOnDroid** — updates through your F-Droid client.
- **GitHub Releases / OpenAPK / Belberi** — download and install the new APK over the existing installation. The FOSS and GMS variants include a built-in update checker that notifies you of new releases.
- **Nightly** — re-download from the GitHub Actions link whenever you want the latest build.
