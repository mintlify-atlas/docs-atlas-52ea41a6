The **Themes and colors** screen is reached from **Settings → Appearance → Theme**. It lets you pick a color palette, set the display mode, and preview changes on a live mockup before committing.

## How color generation works

Each palette seed color is passed through the **Material 3 (Material You) color system** via the [materialKolor](https://github.com/jordond/materialkolor) library using the `TonalSpot` palette style and the 2025 color spec. The system generates a full set of tonal roles from that single seed:

| Role | Used for |
|---|---|
| Primary | Key interactive elements, FAB, selected state |
| On Primary | Text and icons on primary surfaces |
| Secondary | Supporting interactive elements |
| Tertiary | Accent elements, complementary highlights |
| Surface / Background | Page and container backgrounds |
| Surface Variant | Cards, chips, input fields |

The color swatches in the picker render a preview tile split into three sections — top half shows `onPrimary`, bottom-left shows `secondary`, bottom-right shows `tertiary` — giving you an accurate preview of how the palette distributes across the UI.

When the Dynamic palette is selected and the device is running Android 12 or later, Metrolist uses the standard `dynamicDarkColorScheme` / `dynamicLightColorScheme` APIs instead of materialKolor, so the colors are identical to other Material You apps on the same device.

## Display mode

The mode selector sits at the top of the theme controls card. Four modes are available, shown as circular swatches:

<CardGroup cols={2}>
  <Card title="System (Auto)" icon="smartphone">
    Follows the Android system dark/light mode setting. The swatch renders with the device's actual dynamic colors when available. This is the default.
  </Card>
  <Card title="Light" icon="sun">
    Forces a light background regardless of system setting.
  </Card>
  <Card title="Dark" icon="moon">
    Forces a dark background. Surface and background colors are derived from the dark variant of the selected palette.
  </Card>
  <Card title="Black (Pure Black)" icon="circle">
    Forces dark mode and replaces the `surface` and `background` color roles with pure `#000000`. All other palette roles remain intact.
  </Card>
</CardGroup>

<Tip>
  Black mode is ideal for OLED and AMOLED displays. Because OLED pixels emit no light when rendering true black, using Black mode in a dark environment can meaningfully extend battery life compared to standard Dark mode.
</Tip>

## Switching themes

<Steps>
  <Step title="Open the theme screen">
    Go to **Settings → Appearance** and tap **Theme**.
  </Step>
  <Step title="Select a display mode">
    Tap one of the four mode circles at the top of the controls card — System, Light, Dark, or Black.
  </Step>
  <Step title="Pick a color palette">
    Scroll the palette row and tap a color swatch. The live mockup above the card updates immediately to preview the combination.
  </Step>
  <Step title="Return to the app">
    Tap the back arrow. The theme applies instantly with no restart required.
  </Step>
</Steps>

## Pure Black mode and the mini player

Enabling Black mode also sets the mini player background to **Pure Black** when the new mini player design is active. This ensures that the mini player does not break the all-black aesthetic on OLED panels.

You can override the mini player background independently from **Settings → Appearance → Mini player background style** if you want a different combination (for example, Black mode with a gradient mini player).
