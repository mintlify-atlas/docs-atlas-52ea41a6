## What is scrobbling?

Last.fm tracks every song you listen to, building a profile of your music taste over time. When you scrobble a track, Last.fm records the song title, artist, and album to your listening history. This history powers Last.fm's charts, recommendations, and social features.

Metrolist has a built-in Last.fm integration — no third-party app required.

## Prerequisites

You need a [Last.fm account](https://www.last.fm/join) to use this feature.

<Note>
  Official Metrolist builds distributed via GitHub Releases include built-in API keys, which are injected securely via GitHub Secrets during the build process. If you are building from source yourself, you need to supply your own API credentials — see the tip below.
</Note>

<Tip>
  If you are building Metrolist from source, obtain a free API key and secret from [last.fm/api/account/create](https://www.last.fm/api/account/create). Then add the credentials as repository secrets in your GitHub fork: `LASTFM_API_KEY` and `LASTFM_SECRET`. The build system injects them automatically via GitHub Actions.
</Tip>

## Connecting your Last.fm account

<Steps>
  <Step title="Open Settings">
    Tap the **Settings** icon in the navigation bar.
  </Step>
  <Step title="Go to Integrations → Last.fm">
    Navigate to **Integrations** and tap **Last.fm**.
  </Step>
  <Step title="Sign in">
    Tap **Sign in**. A login dialog appears asking for your Last.fm **username** and **password**.
  </Step>
  <Step title="Enter your credentials">
    Enter your Last.fm username and password, then tap **Login**. Metrolist authenticates using the Last.fm mobile session API and stores only your session key — your password is never saved.
  </Step>
</Steps>

Once logged in, your username appears in the **Account** section of the Last.fm settings screen.

## What gets scrobbled

Each scrobble submitted to Last.fm includes:

- **Track name** — the song title
- **Artist** — the track's artist
- **Album** — the album the track belongs to (when available)
- **Duration** — the track length in seconds
- **Timestamp** — when playback started

## Scrobbling options

After connecting your account, configure scrobbling behavior under **Settings → Integrations → Last.fm → Options**.

<CardGroup cols={2}>
  <Card title="Enable scrobbling" icon="radio">
    Turns scrobbling on or off. Must be enabled for any tracks to be submitted to Last.fm.
  </Card>
  <Card title="Now Playing" icon="play">
    Sends a "now playing" notification to Last.fm as soon as a track starts, before the scrobble threshold is reached. Requires scrobbling to be enabled.
  </Card>
  <Card title="Send likes" icon="thumbs-up">
    Automatically loves or unloves a track on Last.fm when you like or unlike it in Metrolist.
  </Card>
</CardGroup>

<Note>
  Scrobbling requires an active internet connection. Tracks played offline will not be scrobbled, even if they were downloaded locally.
</Note>

## Scrobbling configuration

Fine-tune when a track is scrobbled under **Settings → Integrations → Last.fm → Scrobbling configuration**.

| Setting | Description | Default |
|---|---|---|
| Minimum track duration | Tracks shorter than this duration are never scrobbled | 30 seconds |
| Scrobble delay (percentage) | How far through a track (as a %) must have elapsed before it scrobbles | 50% |
| Scrobble delay (seconds) | A hard time cap: scrobbles after this many seconds regardless of percentage | 180 seconds |

A track is scrobbled when either the percentage threshold **or** the seconds threshold is reached, whichever comes first — provided the track is at least as long as the minimum duration.

## Disconnecting your account

To remove your Last.fm account from Metrolist:

1. Go to **Settings → Integrations → Last.fm**.
2. In the **Account** section, tap **Sign out**.

Your session key is cleared immediately. No data is deleted from your Last.fm profile.
